System Architecture

Engineered as an event-driven Windows background service.

01

Win32 event listener

Uses native Windows clipboard hooks for immediate capture without CPU polling loops.

02

SQLite WAL storage

Write-Ahead Logging provides lock-free concurrency and persistent local history retention.

03

WebView2 shell

Renders a high-density, accessible frontend through the native Microsoft Edge runtime.

Cryptographic Protection

Guarding confidential tokens, API secrets, and sensitive credentials.

key derivation
Algorithmic key stretching Stretches user passphrases using 100,000 algorithmic rounds.
Cryptographic salt Generates independent 16-byte random values per encryption key.
symmetric payload cipher
Fernet standard Combines AES-128-CBC cipher blocks with authenticated signatures.
Zero-knowledge memory Plaintext variables are decrypted only during active user inspection.
