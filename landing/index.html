Before and after ClipBox

How systematic buffer capture replaces standard clipboard data loss.

standard windows clipboard
Single item retention Copying a second item permanently overwrites your previous copy buffer.
Zero encryption API keys and passwords remain in memory unencrypted and visible in plain text.
Unstructured sorting Code, URLs, and sentences sit in an unsearchable single queue.
with clipbox active
Persistent SQLite database All historical clips stored in local SQLite WAL tables with instant retrieval.
Fernet master passkey Sensitive secrets encrypted using PBKDF2 with AES-128-CBC and HMAC-SHA256.
Deterministic categorization Regex heuristics instantly assign URLs, emails, phone numbers, and source code.

Core capabilities

Engineered for desktop responsiveness, security, and low memory usage.

Sub-millisecond capture

Native Windows clipboard polling avoids heavy frameworks, keeping idle memory footprint below 32 megabytes.

Twenty colour palettes

Ten light themes and ten dark themes configured with CSS variables for instant switching through shortcuts.

Recopy timestamp bump

Re-copying an earlier clip refreshes its recency index and brings it back to the top of your queue.

Inline text editor

Preview any clip with word counts and character stats, or edit stored contents without leaving the app.

Clean user autostart

Optional startup uses standard user registry keys, eliminating administrator prompts and UAC alerts.

JSON export & cleanup

Export full history to structured JSON files in one click and purge unpinned clips older than thirty days.
